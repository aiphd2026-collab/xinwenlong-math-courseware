第一章｜变数法

本章学习如何用正变、反变、联变表示数量之间的关系，并根据已知条件求变数常数及未知量。

知识结构

1.1 正变1.2 反变1.3 联变

关系基本形式
正变y = kx
反变y = kx
联变z = kxy、z = kxy、z = kxy

本章核心：认清变数对象 → 列关系式 → 代入已知值求 k → 求未知量。

1.1｜正变 （第2～6页）

知识要点

若 y 依 x 而正变，则 y 与 x 的比值为固定的非零常数 k。

\(y\propto x\quad\Longrightarrow\quad y=kx\)
正变图像｜y = kx（k > 0）
示意：当 k > 0 时，正变图像是经过原点、向右上方延伸的直线；k < 0 时直线向右下方倾斜。

正变对象也可能是平方、立方或整体式：\(y=kx^2\)、\(y=kx^3\)、\(y=k(x-1)^2\)。

解题步骤：认清正变对象 → 建立公式 → 代入已知值求 k → 求未知量。

1.2｜反变 （第7～10页）

知识要点

当一个变量随着另一个变量按反比例变化时，称为反变。若 \(y\) 依 \(x\) 而反变，则乘积 \(xy\) 是非零常数 \(k\)。

\(y\propto\dfrac1x\quad\Longrightarrow\quad y=\dfrac{k}{x}\quad (x\ne0)\)

反变对象也可能是 \(x^2\)、\(\sqrt{x}\)、\(\sqrt[3]{x}\) 或一个整体式。先辨认对象，再建立关系式。

\(y=\dfrac{k}{x^2}\qquad y=\dfrac{k}{\sqrt{x}}\qquad x=\dfrac{k}{\sqrt[3]{y}}\)

解题步骤：辨认反变对象 → 写出含 \(k\) 的关系式 → 代入已知值求 \(k\) → 求未知量。

示意：当 \(k>0\) 时，\(y=\dfrac{k}{x}\) 在第一象限的一支曲线（对应教材图1-2）。

1.3｜联变 （第11～14页）

知识要点

一个变量同时依两个或以上的量而变，称为联变。先判断每个变量是正变还是反变，再写出关系式。

\(z\propto xy\ \Rightarrow\ z=kxy\)
\(z\propto\dfrac{x}{y}\ \Rightarrow\ z=\dfrac{kx}{y}\)
\(z\propto\dfrac1{xy}\ \Rightarrow\ z=\dfrac{k}{xy}\)

平方、立方根等也可能是正变或反变对象，例如 \(z=\dfrac{ky^2}{x}\)。

解题方法

辨认正变及反变对象 → 列出含 \(k\) 的联变式 → 用已知数据求 \(k\) → 求未知量。实际应用须核对单位及取值范围。
